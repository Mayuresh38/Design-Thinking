Internal Privacy Policy

Last revised: September 20, 2026 | Acme Corporation Information Governance

1. Purpose and Scope

This Privacy Policy outlines the standards and procedures governing data processed within the InternHub onboarding and task management environment. This workspace is an internal enterprise utility engineered exclusively for authorized Acme Corporation personnel, contractors, and onboarding cohorts.

2. Data Collection and Client-Side Storage

InternHub operates under a zero-telemetry, privacy-first design model:

  • Local Persistence Only: Task completion status, custom phases created in Manager Mode, UI preferences, and optional local LLM integration tokens are stored strictly within the client browser via localStorage.
  • No Third-Party Trackers: No marketing pixels, behavioral surveillance scripts, external cookies, or advertising beacons are loaded or executed.
  • No Telemetry Transmission: Operational state does not transfer to external analytics servers or third-party cloud data brokers.

3. API Keys and External Service Integrations

When connecting optional language model endpoints (e.g., OpenAI or Google Gemini):

  • API keys are stored exclusively in local client memory and injected solely into direct, encrypted outbound HTTPS requests initiated by user query execution.
  • Keys are never written to server logs, repository files, or transmitted to centralized company storage.

4. Internal Feedback and Audit Records

Submissions made through the Internal Workflow Feedback and System Auditing module are stored within the local browser runtime and may be exported by designated administrators for organizational process improvement and onboarding optimization.

5. Governance and Contact

For questions regarding data processing standards or to request local storage purge assistance, contact the Acme Information Governance Team at infosec@acmecorp.internal.
